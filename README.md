# 🎬 Movie Data Analysis Project | Python & Data Analytics

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of a movie dataset using Python. The objective is to analyze movie information, popularity, ratings, genres, release dates, and audience voting patterns to discover meaningful insights.

The dataset contains **9,827 movies** and 9 columns, including movie titles, release dates, popularity scores, vote counts, genres, and original languages.

## 🎯 Project Objectives

- Analyze movie popularity and ratings.
- Identify the most popular movies.
- Explore different movie genres.
- Analyze movie release dates and trends.
- Understand audience voting patterns.
- Perform data cleaning and exploratory data analysis.
- Generate meaningful visualizations.

## 📂 Dataset Information

**Dataset Name:** `mymoviedb.csv`

- Total Records: 9,827
- Total Columns: 9
- Missing Values: 0 (based on the provided dataset information)

### Dataset Columns

| Column Name | Description |
|---|---|
| Release_Date | Movie release date |
| Title | Movie title |
| Overview | Movie description |
| Popularity | Movie popularity score |
| Vote_Count | Total number of votes |
| Vote_Average | Average audience rating |
| Original_Language | Original movie language |
| Genre | Movie genre |
| Poster_Url | Movie poster image URL |
